# FR 工作流通用批量工具

在 Windows 本地导入 ComfyUI API 工作流，为每个任务配置自己的输入和输出。工具按入队顺序逐项提交，检查成品保存后再推进。

## 启动

1. 启动 ComfyUI，然后双击 [启动工具.bat](启动工具.bat)。
2. 在 [本地页面](http://127.0.0.1:7869) 打开「环境设置」，确认 ComfyUI 根目录和服务地址。检测连接后保存设置。
3. 若 ComfyUI 使用独立的 input 或 output 目录，在环境设置里填写实际路径。留空时使用根目录下的 input 和 output。

启动脚本优先使用已有的 C:\FR_comfyui\python\python.exe。工具运行端需要 Flask。WebSocket 可用时接收完成事件，断开或缺少 WebSocket 客户端时会自动查询历史。工具运行端的 Python 可以与 ComfyUI 服务端不同。

## 新建和执行任务

1. 每次新建任务先上传本次使用的 **ComfyUI API 工作流 JSON**。也可以选择同一台电脑上的 JSON 路径。画布格式请在 ComfyUI 里重新导出 API 版本。
2. 检查识别出的素材入口和成品节点，填写各自的素材路径及本任务成品保存目录。结果有歧义时可调整开关或通过「添加入口」「添加输出」绑定字段。
3. 点「预览配对」，核对执行顺序、具体路径和未匹配项。缺项可以补齐后重新预览，也可以确认排除后入队。
4. 点「加入队列」。可以继续上传下一份工作流，也可以在队列运行中追加。任务使用入队时的 JSON、节点绑定、环境设置和配对清单。
5. 点「开始队列」。应用每次提交一项，确认成品后自动处理下一项或下一个工作流。队列明细可以查看每项的输入、成品、ComfyUI 编号及错误。

平铺文件批量按 Windows 名称自然排序逐项匹配。「固定单文件」可用同一个文件配合其他批量入口。对于素材全部由工作流自身提供的任务，可以直接配置成品输出并提交一次。

### 双目录批量

给两个支持读取当前目录的入口分别选择「总目录配对子文件夹」。A、B 两侧各提供一个总目录。工具扫描一级子文件夹，先保留同名组，再把两侧剩余的子文件夹各自按自然顺序一一配对，最终按 A 侧名称顺序执行。

例如 A 侧是 组1、组2、组10，B 侧是 参考2、参考10、组2。执行顺序是 组1 配 参考2、组2 配 组2、组10 配 参考10。组内文件匹配和循环仍由上传的工作流完成。一轮 ComfyUI 提交对应一对子目录。

### 暂停和接续

- 点「暂停」后，已经提交的当前项会继续到成品交付。目录型等待当前组全部成品。单文件型等待当前项成品。下一项保持待处理。
- 关闭浏览器页面可以直接重新打开查看。退出工具或重启电脑后，重新打开工具会载入同一份队列，点「继续队列」才会提交新任务。
- 有在途记录时，工具先查询原提交编号或恢复已经开始交付的成品。提交或成品归属无法确认时，队列显示「待确认」并停止派发。在明细检查已有或暂存成品后，可以选择重跑或跳过。明确的单项失败会留档并继续后续项。工作流配置被 ComfyUI 拒绝时，该工作流的剩余项标记为配置失败。

队列、配对清单、验证过的成品路径和日志保存在项目目录的 **batch_queue.sqlite3**。工具重启时从这个文件恢复。直接保存型工作流每次写入独立的暂存位置，验证后按原目录层级交付。需要确认时，明细会提供部分成品路径。

### 实机环境限制

Scail-2 的实机验收使用 25 帧副本。任务成功提交并进入采样，WanAnimatePlus 的 SamplerFromSettings 调用本机 ComfyUI 未提供的 comfy.model_management.is_directml_enabled，导致该次执行失败。其 SCAIL-2 路径会强制使用 Comfy RoPE，样例现有 RoPE 选项无法绕开这个调用。独立 VHS MP4 收取已通过。原工作流和已安装插件文件未修改。

进程级恢复已在持久化测试数据库上验收。物理关机或电脑重启未在本次实机验证中执行。

### 控制台界面更新

上传区采用青紫星轨动效，通过光球颜色显示识别状态。桌面并排显示新建任务和运行队列，窄屏切换为单列。Edge 中已核对 1440 像素与 390 像素宽度，并通过模拟 ComfyUI 走完上传、配对、入队、当前组保存后暂停和继续。系统要求减少动态效果时，界面会缩减动效。

## 复跑验证

在项目目录运行以下命令。用户样例存在时会自动复核原版和改号版。其他测试使用临时文件和模拟 ComfyUI。

    C:\FR_comfyui\python\python.exe -B -X utf8 -m unittest discover -s tests -v

本次共 12 条测试通过。浏览器使用 Edge 和 Playwright 验收。正常应用入口另用隔离端口与数据库启动确认。
