# FR_工作流通用批量工具

这是一个本地网页工具，用来导入 ComfyUI API 工作流 JSON，自动识别图片/视频上传节点和保存节点，然后批量提交任务。

## 启动

双击 `启动工具.bat`。

如果没有自动打开浏览器，手动访问：

```text
http://127.0.0.1:7869
```

## 换电脑使用

首次打开后，在“环境设置”里修改：

- ComfyUI 根目录，例如 `C:\FR_comfyui`
- ComfyUI Python，例如 `C:\FR_comfyui\python\python.exe`
- ComfyUI 服务地址，默认 `http://127.0.0.1:8188`

设置会保存到 `config.json`。换电脑时只需要重新填一次路径。

## 使用流程

1. 先启动 ComfyUI，确认服务地址能打开。
2. 双击启动本工具。
3. 导入 ComfyUI 导出的 API 工作流 JSON。
4. 检查自动识别出的节点编号和用途。
5. 给每个输入节点选择单文件或文件夹。
6. 选择输出保存目录。
7. 点击“开始批量”。

文件夹批量会按 Win11 风格自然排序，例如 `1, 2, 10`。

任务结果默认每 20 秒向 ComfyUI 查询一次，适合视频工作流长时间运行。
